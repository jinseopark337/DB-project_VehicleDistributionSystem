# DB-project_VehicleDistributionSystem
Database system project using MySQL and C++ for vehicle distribution and assembly management.

# Vehicle Distribution & Assembly System

# Overview

This project is a database system for vehicle distribution and assembly management developed as part of a university Database Systems course.

The project covers the complete development process, including database design, normalization, SQL implementation, and C++ integration using the MySQL C API.
